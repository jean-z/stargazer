# 今晚观星 · Stargazer

打开就知道**今晚适不适合看星星**：观星指数、天光时间线、可见行星、
月相与未来 60 天天象日历。手机优先的 Web App（桌面打开是居中单列）。

"太空科普系列"第五弹（遨游太阳系 → 潜入深渊 → 日月食模拟器 → 风之镜 → 今晚观星）。

## 运行

```bash
npm install --registry=https://registry.npmmirror.com
npm run dev     # → http://localhost:5177
npm test        # 天文层回归测试（12 项，Node 直接跑）
```

## 功能

- **观星指数**：综合月相照亮比与月亮是否在夜间窗口，给出 0-100 评分与优/良/一般/差
- **今日天光时间线**：日出、日落、天文昏影终/黎明（太阳 -18°）、月出月落，夜间区间高亮
- **可见行星**：水金火木土按 Schlyter 轨道模型计算地心赤道坐标，
  当地 22:30 高度 > 10° 且太阳低于 -6° 即判可见，附近似星等/高度/方位
- **月亮**：真实月相绘制（终止线椭圆法）、照亮比、当前高度方位、升落时刻
- **60 天天象日历**：朔/上弦/望/下弦（黄经差过零 + 二分细化到小时）、
  年度八大流星雨、日食/月食（复用日食模拟器的扫描器）

## 位置

默认宁波（29.9°N, 121.6°E），点「📍」用浏览器定位换成你的位置。

## 精度声明

- 升落/晨昏影：10 分钟扫描 + 二分细化，误差 ~1 分钟
- 行星位置：Schlyter 模型，误差 ~1 角分，星等为简化公式（±0.3 等）
- 日月食时刻：地心近似，误差可达数十分钟
- 流星雨峰值日期为年历固定值（实际每小时流量受当晚月相/天气影响）

## 小程序平移路径

纯计算 + 单页 UI，无浏览器强依赖 API（定位可用微信 `wx.getLocation` 替换）。
迁移步骤：`uni-app` 或 Taro 包壳 → 页面改为小程序页面组件 →
Canvas 月相绘制换 `canvas` 2d 接口 → 申请类目"工具-天文"。

## 架构

```
src/
  astro/ephemeris.js   # 太阳/月球星历 + 日月食扫描（复用自 eclipse-sim）
  astro/sky.js         # 赤道坐标/升落扫描/晨昏影/行星位置（纯函数，Node 可测）
  data/meteors.js      # 年度流星雨表
  data/calendar.js     # 60 天天象合成
  components/Panels.jsx# 五张卡片
  App.jsx              # 计算管线 + 页面组装
```
